# Kevin (PC Version)

Masaustunde yasayan, cagrildiginda konusan AI karakter. Electron tabanli, Windows + Linux hedefli.

## Faz durumu

- **Faz 0 (bu commit):** Transparan overlay pencere, tiklanabilir/tiklanamaz bolge ayrimi, bosta rastgele gezinme animasyonu, cagirma kancasi (placeholder), konusma balonu (placeholder).
- **Faz 1:** LLM baglantisi (kullanici kendi API key'ini girer - NVIDIA/Groq), sesli sohbet (Piper TTS + whisper.cpp STT), ilk kurulum sihirbazi (isim, dil, key).
- **Faz 2:** Ekran/kamera gorme (vision), davranis genisletme (elle gosterme, mouse ile oynama vb).
- **Faz 3:** Arka planda konusma ozetleme / hafiza sistemi.

## Calistirma

```bash
npm install
npm start
```
