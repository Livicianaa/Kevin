# Kevin

[Türkçe](../../README.md) · [English](README.en.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · **Русский** · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [اردو](README.ur.md) · [Bahasa Indonesia](README.id.md)

ИИ-друг, который живёт на твоём рабочем столе, разговаривает, узнаёт тебя и умеет пользоваться компьютером.
3D-персонаж в стиле Minecraft: гуляет по экрану, садится, прислонившись к краю, а ещё его можно схватить и
бросить. Скажи его имя — он повернётся к тебе и ответит вслух.

## Скачать

Из [последнего релиза](https://github.com/Livicianaa/Kevin/releases/latest):

| Система | Файл | Как открыть |
|---|---|---|
| Windows 10/11 | `Kevin-Kurulum.exe` | Запусти установщик. На рабочем столе появится ярлык Kevin. |
| Windows (без установки) | `Kevin-Windows.zip` | Распакуй в папку, дважды щёлкни `Kevin\Kevin.exe`. |
| Linux | `Kevin-x86_64.AppImage` | Правый клик > Свойства > разрешить запуск, затем двойной щелчок. В терминале: `chmod +x Kevin-x86_64.AppImage && ./Kevin-x86_64.AppImage` |

Если Windows пишет «Система Windows защитила ваш компьютер», выбери «Подробнее» > «Выполнить в любом случае».
При первом запуске Кевин несколько секунд готовится (заставка), потом падает на рабочий стол.

## Первая настройка: ключ ИИ

Чтобы говорить, Кевину нужен сервис ИИ. У каждого свой ключ; он хранится только на твоём компьютере.

1. При первом запуске Кевин сам открывает настройки (потом: **правый клик** по персонажу > **ИИ**).
2. Выбери провайдера и нажми **Получить ключ**. Бесплатный ключ в Groq: [console.groq.com/keys](https://console.groq.com/keys)
3. Вставь ключ. Список моделей загрузится сам; если ключ верный, появится «Подключено».
4. **Сохранить**.

Без интернета: выбери **Локально (Ollama)**, установи [Ollama](https://ollama.com/download) и скачай модель
(`ollama pull qwen3:8b`).

## Что попробовать

- Скажи **«Кевин»** (или средний клик по нему) и говори: «какая погода?», «включи лоу-фай на YouTube»,
  «посмотри на экран, что это?»
- **Расскажи о себе:** «меня зовут Али, пью кофе без сахара». Он запомнит; поправь — научится. На странице «Чат»
  в меню видно и можно удалить то, что он знает.
- **Попроси код:** «напиши кубик на Python». Он не читает его вслух, а печатает по буквам в своём окне.
- **Камера** (если включена): «посмотри на меня», «это я, запомни меня», «что у меня в руке?»
- **Музыка:** включи песню — он танцует (под видео нет). Во время разговора двигается по настроению.
- **Физика:** хватай, тащи, бросай; тяни медленно за руку — он спотыкается. Упав, встаёт сам.
- **Меню (правый клик):** добавить скины (скин Minecraft 64x64, `+`), размер, язык, поведение. Esc закрывает.
- **11 языков:** Türkçe, English, Español, Français, Deutsch, Português, Русский, العربية, हिन्दी, اردو,
  Bahasa Indonesia. Голос языка скачивается при первом выборе (~60 МБ).

## Требования

- 64-битный Linux или Windows 10/11, микрофон, динамики
- Рекомендуется 8 ГБ ОЗУ. Кевин проверяет компьютер при каждом запуске; на слабых машинах он меньше двигается
  и работает с меньшей частотой кадров.
- Интернет для ИИ (или локальная Ollama)

## Известные ограничения

- **Windows:** танцы под музыку, управление экраном и камера пока работают только в Linux. Чат, голос, меню,
  скины и физика работают и в Windows.
- **Linux:** в основном проверено в Hyprland. В других окружениях прозрачность и «поверх всех окон» могут отличаться.
- Fresh Animations не входит в пакет (лицензия запрещает распространение); Кевин ходит со встроенными анимациями.
  Если он у тебя есть, положи `player.jem` в папку приложения `bin/cem/`.

## Где настройки и данные?

| | Linux | Windows |
|---|---|---|
| Настройки, ключ, память, история, скины | `~/.config/kevin-pc-version/` | `%APPDATA%\kevin-pc-version\` |

Удали эту папку, чтобы сбросить Кевина.

## Из исходников (для разработчиков)

У Кевина две части: **тело** (`body/`, Godot 4.7 + физика Jolt) и **мозг** (Electron: голос, чат, инструменты).
Тело само запускает мозг.

```bash
npm install
npm run build:skin
body/run.sh
```

`bin/` (голос Piper, распознавание whisper.cpp и их модели) не хранится в git из-за размера; список — в
[турецком README](../../README.md). Пакеты: `scripts/paketle.sh [linux|windows|hepsi]`.
