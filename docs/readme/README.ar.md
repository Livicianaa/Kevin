# Kevin

صديق بالذكاء الاصطناعي يعيش على سطح مكتبك، يتكلم ويتعرف عليك ويستطيع استخدام حاسوبك.
شخصية ثلاثية الأبعاد بأسلوب ماينكرافت: يتجول على الشاشة، ويجلس مستندا إلى الحافة، ويمكنك الإمساك به ورميه.
قل اسمه فيلتفت إليك ويتكلم بصوت مسموع.

## التنزيل

من [أحدث إصدار](https://github.com/Livicianaa/Kevin/releases/latest):

| النظام | الملف | طريقة الفتح |
|---|---|---|
| Windows 10/11 | `Kevin-Kurulum.exe` | شغّل المثبّت، فيظهر اختصار Kevin على سطح المكتب. |
| Windows (دون تثبيت) | `Kevin-Windows.zip` | فك الضغط في مجلد ثم انقر مرتين على `Kevin\Kevin.exe`. |
| Linux | `Kevin-x86_64.AppImage` | نقر أيمن > خصائص > اجعله قابلا للتنفيذ، ثم انقر مرتين. من الطرفية: `chmod +x Kevin-x86_64.AppImage && ./Kevin-x86_64.AppImage` |

إذا ظهرت رسالة "حمى Windows جهاز الكمبيوتر"، اختر "مزيد من المعلومات" > "تشغيل على أي حال".
عند التشغيل الأول يستعد كيفن لبضع ثوان (شاشة البداية) ثم يسقط على سطح مكتبك.

## الإعداد الأول: مفتاح الذكاء الاصطناعي

يحتاج كيفن إلى خدمة ذكاء اصطناعي ليتكلم. كل شخص يستخدم مفتاحه الخاص، ويُحفظ على جهازك فقط.

1. عند التشغيل الأول يفتح كيفن إعداداته بنفسه (لاحقا: **نقر أيمن** على الشخصية > **الذكاء الاصطناعي**).
2. اختر مزودا واضغط **احصل على مفتاح**. مفتاح مجاني من Groq: [console.groq.com/keys](https://console.groq.com/keys)
3. الصق المفتاح. تظهر قائمة النماذج تلقائيا، وإذا كان المفتاح صحيحا تظهر كلمة "متصل".
4. **حفظ**.

للاستخدام دون إنترنت اختر **محلي (Ollama)**: ثبّت [Ollama](https://ollama.com/download) ونزّل نموذجا
(`ollama pull qwen3:8b`).

## ما يمكنك تجربته

- قل **"كيفن"** (أو انقر عليه بالزر الأوسط) ثم تكلم: "كيف الطقس؟"، "شغّل لو-فاي على يوتيوب"، "انظر إلى شاشتي، ما هذا؟"
- **حدثه عن نفسك:** "اسمي علي، أشرب القهوة بلا سكر". سيتذكر، وإذا صححته يتعلم. في صفحة المحادثة في القائمة ترى ما يعرفه وتحذفه.
- **اطلب كودا:** "اكتب نرد بايثون". لا يقرأه بصوت عال، بل يكتبه حرفا حرفا في نافذته.
- **الكاميرا** (إذا فُعّلت): "انظر إلي"، "هذا أنا، تذكرني"، "ماذا أمسك؟"
- **الموسيقى:** شغّل أغنية فيرقص (لا يرقص مع الفيديو). وأثناء الكلام يتحرك حسب مزاجه.
- **الفيزياء:** أمسكه واسحبه وارمه؛ اسحب ذراعه ببطء فيتعثر. ينهض بعد السقوط.
- **القائمة (نقر أيمن):** إضافة سكنات (سكن ماينكرافت 64x64، `+`)، الحجم، اللغة، السلوك. Esc للإغلاق.
- **11 لغة:** Türkçe، English، Español، Français، Deutsch، Português، Русский، العربية، हिन्दी، اردو، Bahasa Indonesia.
  يُنزَّل صوت اللغة في المرة الأولى (حوالي 60 ميغابايت).

## المتطلبات

- Linux بنظام 64 بت أو Windows 10/11، ميكروفون، مكبرات صوت
- يُنصح بذاكرة 8 غيغابايت. يقيس كيفن حاسوبك عند كل تشغيل؛ على الأجهزة الأضعف يتحرك أقل ويعمل بمعدل إطارات أقل.
- إنترنت للذكاء الاصطناعي (أو Ollama محليا)

## قيود معروفة

- **Windows:** الرقص مع الموسيقى والتحكم في الشاشة والكاميرا تعمل حاليا على Linux فقط. المحادثة والصوت والقائمة
  والسكنات والفيزياء تعمل على Windows أيضا.
- **Linux:** جُرّب غالبا على Hyprland. قد تختلف الشفافية و"دائما في المقدمة" في بيئات سطح المكتب الأخرى.
- لا تتضمن الحزمة Fresh Animations (ترخيصها يمنع إعادة التوزيع)، فيمشي كيفن بحركات مدمجة.
  إذا كانت لديك، ضع `player.jem` في مجلد `bin/cem/` الخاص بالتطبيق.

## أين الإعدادات والبيانات؟

| | Linux | Windows |
|---|---|---|
| الإعدادات والمفتاح والذاكرة والسجل والسكنات | `~/.config/kevin-pc-version/` | `%APPDATA%\kevin-pc-version\` |

احذف هذا المجلد لإعادة ضبط كيفن.

## التشغيل من الشيفرة (للمطورين)

لكيفن جزءان: **الجسم** (`body/`، Godot 4.7 + فيزياء Jolt) و**الدماغ** (Electron: الصوت والمحادثة والأدوات).
يشغّل الجسم الدماغ بنفسه.

```bash
npm install
npm run build:skin
body/run.sh
```

مجلد `bin/` (صوت Piper والتعرف على الكلام whisper.cpp ونماذجهما) ليس في git بسبب حجمه؛ القائمة في
[README التركي](../../README.md). الحزم: `scripts/paketle.sh [linux|windows|hepsi]`.
