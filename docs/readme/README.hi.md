Minecraft जैसा 3D किरदार: स्क्रीन पर घूमता है, किनारे से टेक लगाकर बैठता है, और तुम उसे पकड़कर फेंक
सकते हो। उसका नाम लो, वह तुम्हारी ओर मुड़कर बोलेगा।

## डाउनलोड

[नवीनतम रिलीज़](https://github.com/Livicianaa/Kevin/releases/latest) से:

| सिस्टम | फ़ाइल | कैसे खोलें |
|---|---|---|
| Windows 10/11 | `Kevin-Kurulum.exe` | इंस्टॉलर चलाओ। डेस्कटॉप पर Kevin का शॉर्टकट आ जाएगा। |
| Windows (बिना इंस्टॉल) | `Kevin-Windows.zip` | किसी फ़ोल्डर में निकालो, `Kevin\Kevin.exe` पर डबल-क्लिक करो। |
| Linux | `Kevin-x86_64.AppImage` | राइट-क्लिक > Properties > executable चुनो, फिर डबल-क्लिक। टर्मिनल: `chmod +x Kevin-x86_64.AppImage && ./Kevin-x86_64.AppImage` |

अगर Windows "Windows protected your PC" दिखाए, तो "More info" > "Run anyway" चुनो।
पहली बार केविन कुछ सेकंड तैयार होता है (शुरुआती स्क्रीन), फिर तुम्हारे डेस्कटॉप पर गिरता है।

## पहली सेटिंग: AI कुंजी

बात करने के लिए केविन को एक AI सेवा चाहिए। हर कोई अपनी कुंजी लगाता है; वह सिर्फ़ तुम्हारे कंप्यूटर पर रहती है।

1. पहली बार केविन खुद सेटिंग्स खोलता है (बाद में: किरदार पर **राइट-क्लिक** > **AI**)।
2. प्रदाता चुनो और **कुंजी लो** दबाओ। Groq पर मुफ़्त कुंजी: [console.groq.com/keys](https://console.groq.com/keys)
3. कुंजी पेस्ट करो। मॉडल सूची अपने आप आती है; कुंजी सही हो तो "जुड़ गया" दिखेगा।
4. **सहेजें**।

बिना इंटरनेट के: **लोकल (Ollama)** चुनो, [Ollama](https://ollama.com/download) इंस्टॉल करो और मॉडल लो
(`ollama pull qwen3:8b`)।

## क्या-क्या आज़मा सकते हो

- **"केविन"** बोलो (या उस पर मिडल-क्लिक), फिर बात करो: "मौसम कैसा है?", "YouTube पर लो-फ़ाई चलाओ",
  "मेरी स्क्रीन देखो, यह क्या है?"
- **अपने बारे में बताओ:** "मेरा नाम अली है, मैं बिना चीनी की कॉफ़ी पीता हूँ"। वह याद रखेगा; सुधारो तो सीखेगा।
  मेनू के बातचीत पेज में वह जो जानता है, दिखता है और हटाया जा सकता है।
- **कोड लिखवाओ:** "Python में पासा बनाओ"। वह उसे पढ़कर नहीं सुनाता, अपनी खिड़की में अक्षर-अक्षर लिखता है।
- **कैमरा** (चालू हो तो): "मुझे देखो", "यह मैं हूँ, याद रखो", "मेरे हाथ में क्या है?"
- **संगीत:** गाना चलाओ, वह नाचेगा (वीडियो पर नहीं)। बोलते समय मूड के हिसाब से हिलता है।
- **फ़िज़िक्स:** पकड़ो, खींचो, फेंको; बाँह धीरे खींचो तो लड़खड़ाता है। गिरकर खुद उठता है।
- **मेनू (राइट-क्लिक):** स्किन जोड़ो (64x64 Minecraft स्किन, `+`), आकार, भाषा, व्यवहार। Esc से बंद।
- **11 भाषाएँ:** Türkçe, English, Español, Français, Deutsch, Português, Русский, العربية, हिन्दी, اردو,
  Bahasa Indonesia। किसी भाषा की आवाज़ पहली बार डाउनलोड होती है (~60 MB)।

## ज़रूरतें

- 64-बिट Linux या Windows 10/11, माइक्रोफ़ोन, स्पीकर
- 8 GB RAM सुझाई जाती है। केविन हर बार शुरू होने पर कंप्यूटर जाँचता है; कमज़ोर मशीन पर कम हिलता है और कम fps पर चलता है।
- AI के लिए इंटरनेट (या लोकल Ollama)

## ज्ञात सीमाएँ

- **Windows:** संगीत पर नाचना, स्क्रीन कंट्रोल और कैमरा अभी सिर्फ़ Linux पर हैं। बातचीत, आवाज़, मेनू, स्किन और
  फ़िज़िक्स Windows पर भी चलते हैं।
- **Linux:** ज़्यादातर Hyprland पर जाँचा गया। दूसरे डेस्कटॉप पर पारदर्शिता और "हमेशा ऊपर" अलग हो सकते हैं।
- Fresh Animations शामिल नहीं है (उसका लाइसेंस दोबारा बाँटने की अनुमति नहीं देता); केविन अपने एनिमेशन से चलता है।
  अगर तुम्हारे पास है, तो `player.jem` को ऐप के `bin/cem/` फ़ोल्डर में रखो।

## सोर्स से चलाना (डेवलपर)

केविन के दो हिस्से हैं: **शरीर** (`body/`, Godot 4.7 + Jolt फ़िज़िक्स) और **दिमाग** (Electron: आवाज़, बातचीत,
टूल)। शरीर दिमाग को खुद शुरू करता है।

```bash
npm install
npm run build:skin
body/run.sh
```

`bin/` (Piper आवाज़, whisper.cpp पहचान और उनके मॉडल) आकार की वजह से git में नहीं है; सूची
[तुर्की README](../../README.md) में है। पैकेज: `scripts/paketle.sh [linux|windows|hepsi]`।
