تمہارے ڈیسک ٹاپ پر رہنے والا AI دوست جو بات کرتا ہے، تمہیں جانتا ہے اور کمپیوٹر چلا سکتا ہے۔
Minecraft جیسا 3D کردار: اسکرین پر گھومتا ہے، کنارے سے ٹیک لگا کر بیٹھتا ہے، اور تم اسے پکڑ کر پھینک سکتے ہو۔
اس کا نام لو تو وہ تمہاری طرف مڑ کر بولے گا۔

## ڈاؤن لوڈ

[تازہ ترین ریلیز](https://github.com/Livicianaa/Kevin/releases/latest) سے:

| سسٹم | فائل | کیسے کھولیں |
|---|---|---|
| Windows 10/11 | `Kevin-Kurulum.exe` | انسٹالر چلاؤ۔ ڈیسک ٹاپ پر Kevin کا شارٹ کٹ آ جائے گا۔ |
| Windows (بغیر انسٹال) | `Kevin-Windows.zip` | کسی فولڈر میں نکالو، `Kevin\Kevin.exe` پر ڈبل کلک کرو۔ |
| Linux | `Kevin-x86_64.AppImage` | رائٹ کلک > Properties > executable چنو، پھر ڈبل کلک۔ ٹرمینل: `chmod +x Kevin-x86_64.AppImage && ./Kevin-x86_64.AppImage` |

اگر Windows کہے "Windows protected your PC" تو "More info" > "Run anyway" چنو۔
پہلی بار کیون چند سیکنڈ تیار ہوتا ہے (آغاز اسکرین)، پھر تمہارے ڈیسک ٹاپ پر گرتا ہے۔

## پہلی ترتیب: AI کلید

بات کرنے کے لیے کیون کو ایک AI سروس چاہیے۔ ہر کوئی اپنی کلید لگاتا ہے؛ وہ صرف تمہارے کمپیوٹر پر رہتی ہے۔

1. پہلی بار کیون خود ترتیبات کھولتا ہے (بعد میں: کردار پر **رائٹ کلک** > **AI**)۔
2. فراہم کنندہ چنو اور **کلید لو** دباؤ۔ Groq پر مفت کلید: [console.groq.com/keys](https://console.groq.com/keys)
3. کلید پیسٹ کرو۔ ماڈل فہرست خود آ جاتی ہے؛ کلید درست ہو تو "جڑ گیا" نظر آئے گا۔
4. **محفوظ کریں**۔

بغیر انٹرنیٹ کے: **لوکل (Ollama)** چنو، [Ollama](https://ollama.com/download) انسٹال کرو اور ماڈل لو
(`ollama pull qwen3:8b`)۔

## کیا کیا آزما سکتے ہو

- **"کیون"** کہو (یا اس پر مڈل کلک)، پھر بات کرو: "موسم کیسا ہے؟"، "یوٹیوب پر لو-فائی لگاؤ"، "میری اسکرین دیکھو، یہ کیا ہے؟"
- **اپنے بارے میں بتاؤ:** "میرا نام علی ہے، میں بغیر چینی کی کافی پیتا ہوں"۔ وہ یاد رکھے گا؛ درست کرو تو سیکھے گا۔
  مینو کے گفتگو صفحے میں وہ جو جانتا ہے نظر آتا ہے اور حذف ہو سکتا ہے۔
- **کوڈ لکھواؤ:** "پائتھن میں پانسہ بناؤ"۔ وہ اسے پڑھ کر نہیں سناتا، اپنی کھڑکی میں حرف حرف لکھتا ہے۔
- **کیمرا** (آن ہو تو): "مجھے دیکھو"، "یہ میں ہوں، یاد رکھو"، "میرے ہاتھ میں کیا ہے؟"
- **موسیقی:** گانا لگاؤ، وہ ناچے گا (ویڈیو پر نہیں)۔ بات کرتے ہوئے موڈ کے مطابق حرکت کرتا ہے۔
- **فزکس:** پکڑو، کھینچو، پھینکو؛ بازو آہستہ کھینچو تو لڑکھڑاتا ہے۔ گر کر خود اٹھتا ہے۔
- **مینو (رائٹ کلک):** اسکن شامل کرو (64x64 Minecraft اسکن، `+`)، سائز، زبان، رویہ۔ Esc سے بند۔
- **11 زبانیں:** Türkçe، English، Español، Français، Deutsch، Português، Русский، العربية، हिन्दी، اردو، Bahasa Indonesia۔
  کسی زبان کی آواز پہلی بار ڈاؤن لوڈ ہوتی ہے (تقریباً 60 MB)۔

## ضروریات

- 64 بٹ Linux یا Windows 10/11، مائیکروفون، اسپیکر
- 8 GB RAM تجویز کی جاتی ہے۔ کیون ہر بار شروع ہونے پر کمپیوٹر جانچتا ہے؛ کمزور مشین پر کم حرکت کرتا ہے اور کم fps پر چلتا ہے۔
- AI کے لیے انٹرنیٹ (یا لوکل Ollama)

## معلوم حدود

- **Windows:** موسیقی پر ناچنا، اسکرین کنٹرول اور کیمرا ابھی صرف Linux پر ہیں۔ گفتگو، آواز، مینو، اسکن اور فزکس
  Windows پر بھی چلتے ہیں۔
- **Linux:** زیادہ تر Hyprland پر جانچا گیا۔ دوسرے ڈیسک ٹاپ پر شفافیت اور "ہمیشہ اوپر" مختلف ہو سکتے ہیں۔
- Fresh Animations شامل نہیں (اس کا لائسنس دوبارہ تقسیم کی اجازت نہیں دیتا)؛ کیون اپنی اینیمیشن سے چلتا ہے۔
  اگر تمہارے پاس ہے تو `player.jem` کو ایپ کے `bin/cem/` فولڈر میں رکھو۔

## سورس سے چلانا (ڈویلپر)

کیون کے دو حصے ہیں: **جسم** (`body/`، Godot 4.7 + Jolt فزکس) اور **دماغ** (Electron: آواز، گفتگو، ٹول)۔
جسم دماغ کو خود شروع کرتا ہے۔

```bash
npm install
npm run build:skin
body/run.sh
```

`bin/` (Piper آواز، whisper.cpp پہچان اور ان کے ماڈل) سائز کی وجہ سے git میں نہیں؛ فہرست
[ترکی README](../../README.md) میں ہے۔ پیکجز: `scripts/paketle.sh [linux|windows|hepsi]`۔
